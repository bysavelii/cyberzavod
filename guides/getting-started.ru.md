Cyberzavod даёт ИИ-агенту, которым вы уже пользуетесь, постоянный процесс разработки, проверки, без которых агент не закончит работу, и журнал того, что произошло. Сам он код не пишет и агентом не является.

## Что нужно

- Node 22 или новее, git и ИИ-агент для кода: [Claude Code](https://claude.com/claude-code) или [Codex CLI](https://github.com/openai/codex).
- Git-репозиторий. В пустой папке сначала выполните `git init`.

## Пять шагов

1. Перейдите в проект:

   ```bash
   cd my-project
   ```

2. Подключите Cyberzavod. Он покажет, что нашёл, и спросит `Продолжить? [Y/n]`:

   ```bash
   npx cyberzavod init
   ```

   Для Codex CLI выполните `npx cyberzavod init --agent codex`. Закоммитьте файлы из списка.

3. Откройте в проекте Claude Code (или Codex).
4. Запустите `/setup` (в Codex — `$setup`). Он заполнит `AGENTS.md` по вашему коду и один раз прогонит проверки проекта. Закоммитьте то, что он изменил.
5. Поставьте задачу:

   ```text
   /feature "Добавить тёмную тему"
   ```

   В Codex скиллы вызывают через `$`: `$feature "Добавить тёмную тему"`.

Готово. Задача проходит процесс:

**Постановка → Код → Ревью → Проверки → Фиксация**

План одобряете вы. Агенты пишут код, проверяют его на ревью и сверяют с планом. Пока проверки красные, агент не может закончить, а в конце вы получаете коммиты. По желанию `/publish-recording` превращает сессию в запись, которую можно проиграть на сайте.

## Важно знать

- **Всё локально.** Cyberzavod работает локально: наружу ничего не уходит, пока вы сами не опубликуете запись (`/publish-recording`, `share`). `init`, `sync`, `status`, `doctor` и хуки никуда ничего не отправляют.
- **Два агента.** Cyberzavod задуман независимым от агента. Поддержаны Claude Code (по умолчанию) и Codex CLI (`init --agent codex`); других агентов пока нет. Проектом управляет один агент. Codex запускает хуки проекта, только если проекту доверяют, поэтому `init` отмечает проект и его хуки доверенными в вашем собственном конфиге Codex, вне проекта; `disconnect` это возвращает.
- **Ваши файлы в безопасности.** Cyberzavod не перезаписывает молча файлы, которые ему не принадлежат. Повторный `init` ничего не меняет.
- **Что-то не так?** Запустите `npx cyberzavod doctor`: он проверит подключение и подскажет, как починить каждую проблему.
- **Не подошло?** `npx cyberzavod disconnect` покажет, что уберёт и что оставит, и уберёт только добавленное Cyberzavod. Код, `AGENTS.md` и журнал останутся.
