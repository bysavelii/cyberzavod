# Пакет цеха (packages/viewer)

`@cyberzavod/viewer` — второй npm-пакет Cyberzavod: цех для записей и черновиков самого человека (`npx cyberzavod view`). Это только упаковка: интерфейс живёт в `apps/web` (`src/app/viewer/`, виджеты и острова сайта, правила — в `apps/web/AGENTS.md`, раздел «Цех для `cyberzavod view`»), сервер и чтение журнала — в `packages/cli`. Здесь Vite собирает цех в статику и лежит крошечный bin.

## Правила

- **Без зависимостей.** В `package.json` нет `dependencies`: всё, что нужно цеху, уже в `dist/`. `devDependencies` — только сборка (`vite`, `vite-plugin-solid`, `typescript`, `@types/node`). Версия `vite` — та же, что разрешает Astro сайта (одна копия в `pnpm-lock.yaml`); поднимать их вместе.
- **Версия** пакета равна версии `cyberzavod` (`packages/cli/package.json`): это проверяет тест. Поднимают обе вместе с `HARNESS_VERSION`. `cyberzavod@X.Y.Z` просит `@cyberzavod/viewer@X.Y.Z`.
- **Сборка** (`vite.config.ts`): корень — `apps/web/src/app/viewer`, алиас `@` → `apps/web/src`, плагин Solid, `base: "./"` (адреса относительные: сервер CLI может отдать файлы по любому пути), выход — `dist/`, без карт исходников. Сеть не нужна: ни в `index.html`, ни при загрузке ничего не берётся снаружи, шрифты (`@fontsource-variable/*`) лежат в `dist/assets/`. Тест проверяет, что в `index.html` нет `http://` и `https://`.
- **Заглушка `.astro`** (`build/astro-component-stub.ts`): `index.ts` слайсов сайта отдаёт рядом с Solid-островами и компоненты `.astro`; цеху они не нужны, и сборка подменяет такой файл функцией, которая падает при вызове. Использованный по ошибке компонент не пройдёт незамеченным.
- **Лицензии** (`build/licenses.ts`): плагин `generateBundle` берёт каждый пакет из `node_modules`, до которого дошла сборка (id модулей приводятся к «/», чтобы путь Windows читался так же), и пишет в `dist/THIRD_PARTY_LICENSES` его имя, версию, лицензию и тексты файлов `LICENSE*`/`LICENCE*`/`NOTICE*`. Сборка падает, если не нашла ни одного пакета, если у манифеста нет поля `license` и если у пакета нет файла лицензии. Исключение — явный список `PACKAGES_WITHOUT_LICENSE_FILE` (пакет лицензии не кладёт, только поле в манифесте): для такого пакета собирается полный текст MIT с владельцем из `author` манифеста, а смена лицензии или автора роняет сборку. В список добавляют после проверки репозитория пакета, по одному.
- **bin** (`bin/cyberzavod-viewer.mjs`) печатает абсолютный путь к `dist/` и выходит с 0. Файлы раздаёт CLI, а не пакет: чтение журнала, предпросмотр черновиков, тексты на языке CLI и безопасность путей остаются в одном месте.
- **Что в архиве** (`files`): `bin`, `dist`, плюс `LICENSE` и `README.md` и `package.json`, которые npm кладёт сам. `LICENSE` — копия корневого, её делает `prepack` (в git не идёт), он же собирает `dist/`. Папка `dist/` есть только после сборки: `make check-web` (скрипт `check`) собирает её до тестов.
- Тесты — Vitest рядом с кодом (`vitest.config.ts` свой: иначе Vitest взял бы `vite.config.ts` с корнем в исходниках цеха).
